STREAMBOX MEGA DEMO

This version contains 30 original, locally hosted demo video clips and thumbnails.
No YouTube embeds are required for the built-in videos.

FILES:
- index.html
- style.css
- script.js
- videos/ (30 MP4 demo clips)
- thumbnails/ (30 JPG thumbnails)

FEATURES:
- Search
- Category filters
- 30 playable local videos
- Upload a local video for the current browser session
- Likes, save, share, subscribe buttons
- Responsive layout
- Collapsible sidebar

IMPORTANT:
These are original demo/title-card clips generated for the project, not downloaded YouTube videos.
GitHub Pages can host these static files. A school-managed network can still block a GitHub Pages site itself; there is no code change that can guarantee bypassing a school filter.
